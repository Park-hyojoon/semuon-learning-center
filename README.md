# 세무온 · 전산세무 2급 학습센터

이론·일반전표·매입매출전표, 의제매입·부가가치세 신고서, 급여·연말정산 학습과 오늘 복습을 지원합니다. 학습 단원은 교재의 4과목·34개 소단원 순서로 선택합니다. 105회 이하 기출은 원문·정답·기록을 보관하며 학습 목록·검색·복습에서 제외합니다.

GitHub Pages 주소에서 PC·모바일로 접속합니다. 문제 목록에서 기출 회차와 정렬을 선택하세요.

학습기록은 각 브라우저에 누적 저장됩니다. 최근 기록 화면에는 30개를 표시하지만 모든 이전 기록도 취약점·복습 분석과 전체 백업에 포함됩니다. 배포 문제를 중복 저장하지 않도록 저장 형식을 개선했으며 기존 기록을 이어갑니다. PC·휴대폰 사이 기록 이동은 설정 · 백업의 내보내기/가져오기를 사용합니다. 기존 로컬 파일에서의 기록도 전체 백업으로 이동할 수 있습니다.

76회는 2017년, 77·78·79·80·81·82회는 2018년, 83·87·88회는 2019년, 90·91·92·93·94회는 2020년, 95·96·97·98회는 2021년, 119·120·121·122·123·124회는 2025년, 125·126·127회는 2026년 제공 답안 기준입니다. 현재 시험 기준과 구분해 학습합니다.

이 저장소는 실행 전용 파일로 구성됩니다. 원본 TXT/HWP/PDF, 개인 노트·백업·실제 학습기록은 포함하지 않습니다. 원본·확정 답안에 따라 등록된 문제와 화면용 HTML/SVG 증빙을 사용합니다.

공통 입력기·채점기·추천기는 shared/에 로컬 원본의 배포 스냅샷을 포함합니다. 변경은 원본 학습센터에서 관리하고 배포 내보내기로 갱신합니다.
