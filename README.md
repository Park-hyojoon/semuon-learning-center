# 세무온 · 전산세무 2급 학습센터

이론·일반전표·매입매출전표, 의제매입·부가가치세 신고서, 급여·연말정산 학습과 오늘 복습을 지원합니다. 대표 태그(부가가치세·소득세 등)는 분야와 회차를 합쳐 표시합니다.

GitHub Pages 주소에서 PC·모바일로 접속합니다. 문제 목록에서 기출 회차와 정렬을 선택하세요.

학습기록은 각 브라우저에 저장됩니다. PC·휴대폰 사이 기록 이동은 설정 · 백업의 내보내기/가져오기를 사용합니다. 기존 로컬 파일에서의 기록도 전체 백업으로 이동할 수 있습니다.

76회는 2017년, 77·78·79·80·81회는 2018년 제공 답안 기준입니다. 현재 시험 기준과 구분해 학습합니다.

이 저장소는 실행 전용 파일로 구성됩니다. 원본 TXT/HWP/PDF, 개인 노트·백업·실제 학습기록은 포함하지 않습니다. 원본·확정 답안에 따라 등록된 문제와 화면용 HTML/SVG 증빙을 사용합니다.

공통 입력기·채점기·추천기는 shared/에 로컬 원본의 배포 스냅샷을 포함합니다. 변경은 원본 학습센터에서 관리하고 배포 내보내기로 갱신합니다.
